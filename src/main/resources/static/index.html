Campaign lookalike search

Describe a campaign you are planning. The service searches a set of past campaigns, picks the three closest and explains each pick. Every explanation cites a campaign id, and a check rejects any id that the search did not return.

This hosted demo runs on 120 synthetic campaigns and on offline stand-in models, so the matches reflect shared wording and the figures are invented. It sleeps when idle, and the first request after a break can take a minute while it wakes up.
